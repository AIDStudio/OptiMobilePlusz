# 📱 OptiMobilePlusz (v1.1 Update)

**OptiMobilePlusz** is a high-performance optimization mod specifically designed for **Minecraft 1.21.1 (Fabric)**. It is tailored for mobile devices and users utilizing **PojavLauncher** or **Zalith Launcher**. By using advanced Mixin-based bytecode injection, it forces aggressive rendering optimizations to ensure the highest possible FPS on hardware-constrained ARM devices.

## 📊 Test Device Performance
* **Device**: Poco X5 5G (Snapdragon 695, 6GB RAM)
* **Performance**: Achieved **150-230+ FPS** (Vanilla-like environment, no other optimization mods required).

---

## 🚀 Key Features (New in v1.1!)

### 🛠 Rendering & Graphics
* **OptiZoom (New)**: A built-in, smooth-interpolated zoom function. No need for extra mods like Zoomify. Fully optimized for mobile screens.
* **Smart Chunk Priority**: Rewritten chunk-building logic specifically for mobile CPUs. FPS remains stable even while new chunks are loading.
* **Permanent Turbo Mode**: Enforces the fastest graphical settings (Fast graphics, minimal particles) automatically.
* **Dynamic Lighting Optimization**: Rewrites how the game handles light updates to eliminate lag spikes during movement.

### 🤖 Logic & Entities
* **Aggressive Entity Culling**: Prevents rendering of entities further than 20 blocks away, drastically saving CPU and GPU cycles.
* **Memory Management**: Optimized core logic to minimize object allocation, reducing "Garbage Collector" stutters.

### 📱 Mobile Specialization
* **In-Game FPS Counter**: A custom, pixel-style, color-coded FPS display tailored for mobile visibility.
* **ARM/Pojav Optimized**: Tuned for mobile environments where thermal throttling is a factor.

## 🛠 Installation
1. Use **Fabric Loader** for Minecraft 1.21.1 (Requires Java 21).
2. Download the latest **-RELEASE.jar**.
3. Place it in your `mods` folder and enjoy the boost!
